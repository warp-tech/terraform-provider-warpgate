# warpgate_ssh_own_keys (Data Source)

Retrieves the SSH keys for the Warpgate server.

## Example Usage

```hcl
data "warpgate_ssh_own_keys" "server_keys" {}

output "ssh_host_keys" {
  value = data.warpgate_ssh_own_keys.server_keys.keys
}

# Get the default SSH key
output "default_key" {
  value = [for k in data.warpgate_ssh_own_keys.server_keys.keys : k if k.is_default][0]
}
```

## Attribute Reference

The following attributes are exported:

- `keys` - A list of SSH keys. Each key has the following attributes:
  - `id` - The ID of the key.
  - `label` - The label of the key.
  - `kind` - The type of SSH key (e.g., "Ed25519", "RSA").
  - `public_key` - The public key string.
  - `public_key_base64` - The public key in base64 format.
  - `is_default` - Whether this key is marked as default.

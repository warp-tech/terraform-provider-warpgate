# warpgate_user_admin_role (Resource)

Assigns an admin role to a user in Warpgate. The user gains the admin permissions the role grants.

If the SSO provider the user logs in with has `admin_role_mappings` that mention this admin role, Warpgate adds and removes the assignment on every login to match the user's groups. Manage such roles through the SSO mapping instead of this resource, or the two will fight over the assignment.

## Example Usage

```hcl
resource "warpgate_user" "alice" {
  username = "alice"
}

resource "warpgate_admin_role" "security" {
  name          = "security"
  sessions_view = true
}

resource "warpgate_user_admin_role" "alice_security" {
  user_id       = warpgate_user.alice.id
  admin_role_id = warpgate_admin_role.security.id
}
```

## Argument Reference

The following arguments are supported:

* `user_id` - (Required) The ID of the user to assign the admin role to.
* `admin_role_id` - (Required) The ID of the admin role to assign.

## Attribute Reference

In addition to all arguments above, the following attributes are exported:

* `id` - The combined ID in the format `user_id:admin_role_id`.

## Import

Assignments can be imported using a combined ID with the format `user_id:admin_role_id`.

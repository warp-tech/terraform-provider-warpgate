# warpgate_ssh_key (Resource)

Manages Warpgate server SSH keys. Keys can either be generated by Warpgate (e.g. Ed25519) or imported using an existing private key in OpenSSH/PEM format.

## Example Usage

### Generate a new SSH Key

```terraform
resource "warpgate_ssh_key" "deploy_key" {
  label      = "deploy-key"
  kind       = "Ed25519"
  is_default = true
}

resource "warpgate_target" "production_server" {
  name        = "prod-ssh"
  description = "Production SSH server"

  ssh_options {
    host     = "10.0.0.5"
    port     = 22
    username = "admin"

    public_key_auth {
      key_id = warpgate_ssh_key.deploy_key.id
    }
  }
}
```

### Import an existing private SSH key

```terraform
resource "warpgate_ssh_key" "custom_key" {
  label      = "custom-key"
  secret_key = file("${path.module}/id_ed25519")
  is_default = false
}
```

## Schema

### Required

- `label` (String) Label identifying this SSH key.

### Optional

- `is_default` (Boolean) Whether this SSH key is marked as default for host authentication.
- `kind` (String) The key type for key generation (e.g. `Ed25519`, `Rsa4096`). Defaults to `Ed25519` when generating.
- `secret_key` (String, Sensitive) Private key in OpenSSH or PKCS#8 PEM format for importing an existing key. If not provided, a new key pair will be generated.

### Read-Only

- `id` (String) The ID of this resource (UUID).
- `public_key` (String) The public key string.
- `public_key_base64` (String) The base64-encoded public key body without algorithm prefix.

## Import

SSH keys can be imported using their UUID `id`.

